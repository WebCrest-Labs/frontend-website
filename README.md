# 🌐 WebCrest Labs  
### Engineering the Peak of Digital Excellence

WebCrest Labs is a modern, performance-first digital studio website built with **React**, **Tailwind CSS**, and **Framer Motion**.  
It showcases WebCrest’s services, portfolio, team, and contact flow with a strong focus on **design systems, motion, and user experience**.

---

## ✨ Highlights

- ⚡ Modern React (Vite) architecture
- 🎨 WebCrest Labs design system with light & dark themes
- 🌗 System-aware theme persistence (localStorage + OS preference)
- 🎥 Smooth, purposeful animations using Framer Motion
- 🧠 Clean component-driven structure
- 🖱️ Custom animated cursor (dot + outline)
- 📧 Contact form with `mailto:` based submission
- 📱 Fully responsive across all breakpoints

---

## 🧱 Tech Stack

- **Frontend:** React 18 + Vite
- **Styling:** Tailwind CSS (v4) with CSS variables
- **Animation:** Framer Motion
- **Icons & Assets:** Local SVG/PNG assets
- **Notifications:** react-hot-toast
- **Fonts:** Manrope (Google Fonts)
